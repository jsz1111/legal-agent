# 五案并发证据评估物料

本目录用于本地端到端测试，不是真实当事人的原始证据。材料依据公开案件事实脱敏重构，
只保留验证“证明对象、完整性、来源、冲突和补强建议”所需的最少字段。

| 组别 | 案情 | 公开来源 | 预期重点 |
| --- | --- | --- | --- |
| 01 | 二手手机私下付款后未发货 | 北京市人民检察院第四分院公开案例 | 订单、付款、身份和沟通能否关联 |
| 02 | 演唱会门票代购失败且不退款 | 中山法院网转载人民法院案例 | 委托约定、付款和违约事实 |
| 03 | 非固定场所工作产生加班费争议 | 最高人民法院、人社部、全国总工会典型案例 | 劳动关系、工作内容、时间和工资标准 |
| 04 | 提前退租后房东拒退剩余租金和押金 | 山东法院网公开案例 | 租赁关系、付款、交接和解除通知 |
| 05 | 非机动车逆行造成摩托车驾驶人受伤 | 最高人民法院交通事故典型案例 | 事故责任、伤情、费用和保险情况 |

测试时每组使用独立 `session_id`，先提交 `case.txt`，收敛后再上传该组的 `evidence_*.txt`。
所有文件均应被标记为“上传副本、真实性未核验”；不得因为写有“公开案例”而当作官方原件。
